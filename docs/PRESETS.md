# Пресеты и списки

Подробности для тех, кто хочет разобраться или сделать свою стратегию. Если нужно просто включить — хватит
[README](../README.md).

## Что такое пресет

Пресет — готовый набор параметров `nfqws2` (стратегия). Включённый пресет применяется сразу, если сервис запущен,
`nfqws2` перезапускается. Встроенные пресеты и скачанные можно смотреть, копировать в свои и редактировать копии; свои
пресеты не перезаписываются обновлением.

| id | Что делает |
|---|---|
| `default` | стратегия zapret2 по умолчанию: подмена и разрезание для HTTP и TLS, фейки для QUIC |
| `alt1` | простое разрезание TCP без фейков — самый мягкий вариант, пробуйте первым |
| `alt2` | сегменты в обратном порядке, без фейков |
| `alt3` | разрезание с перекрытием sequence, без фейков |
| `alt4` | фейки с автоподбором TTL (до сервера не доходят) + разрезание |
| `alt5` | настоящие и фейковые сегменты вперемешку (fakedsplit) + MD5 |
| `alt6` | фейковое имя хоста между настоящими сегментами (hostfakesplit) + MD5 |
| `alt7` | данные в SYN (syndata) + разрезание; действует на весь TLS, списки не учитываются |
| `auto` | перебирает стратегии по кругу, пока сайт не открывается (оркестратор `circular`) |
| `discord` | Default + голос Discord (UDP 50000-50100) |
| `general-alt` | порт «general (ALT)» из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube): Discord, YouTube; скачивает списки Flowseal |
| `general-alt-games` | `general-alt` + весь TCP и UDP на портах 1024-65535 (нагружает роутер) |

Это **отправные точки, а не гарантия обхода**: что сработает, зависит от провайдера. Пресеты проверены на корректность
синтаксиса и выполнение, но не на эффективность против конкретного DPI.

Описание в карточке пресета — одна короткая фраза; подробности, предупреждения и пояснения к параметрам лежат в
комментариях самого файла пресета (кнопка «Просмотр»).

## General (ALT) из zapret-discord-youtube

 Пресет `general-alt` — перевод батника «general (ALT)» (winws, zapret1)
на синтаксис `nfqws2`. Чтобы сделать так же из любого другого батника, нужно переписать опции так:

| Батник (winws) | Пресет (nfqws2) |
|---|---|
| `--wf-tcp=…` / `--wf-udp=…` | заголовок `#@tcp_ports:` / `#@udp_ports:` |
| `--dpi-desync=fake,fakedsplit` | `--lua-desync=fake:…` и `--lua-desync=fakedsplit:…` одна за другой |
| `--dpi-desync-fooling=ts` | `tcp_ts=-600000` (для `md5sig` — `tcp_md5`, для `badseq` — `tcp_seq=…`) |
| `--dpi-desync-repeats=6` | `repeats=6` |
| `--dpi-desync-fakedsplit-pattern=0x00` | `pattern=0x00` (это значение по умолчанию); позиция разреза по умолчанию 2 |
| `--ip-id=zero` | `ip_id=zero` |
| `--dpi-desync-fake-tls/-http/-quic=файл.bin` | `--blob=имя:@<BASE>/files/fake/файл.bin` и `blob=имя` в `fake` |
| несколько `--dpi-desync-fake-tls` | несколько `fake` подряд |
| `--filter-udp=443` (протокол неявно) | `--filter-udp=443 --filter-l7=quic --payload=quic_initial` |
| `--filter-l7=discord,stun` | то же плюс `--payload=stun,discord_ip_discovery` |
| `--hostlist=…`, `--hostlist-exclude=…` | то же; свои списки — `<LIST:имя>` |
| `--hostlist-domains=discord.media` | то же |

Что не перенесено или заменено: профили с `ipset-all.txt` (в оригинале в нём лежит одна заглушка, то есть они ничего не
делают) и игровой фильтр (порты 1024-65535: на роутере это много лишнего трафика в очередь; он есть в отдельном пресете
`general-alt-games`, см. ниже); `--ipset-exclude`
(частные сети; роутер и так отдаёт `nfqws2` только трафик наружу); файла `tls_clienthello_www_sferum_ru.bin` нет в
поставке zapret2 — вместо него `tls_clienthello_vk_com.bin`; для голоса Discord взят `quic_initial_www_google_com.bin`.
Чтобы добавить пропущенное, скопируйте пресет («Копировать») и допишите нужные порты и профили.

Пресет объявляет три списка из репозитория Flowseal (`fs_general`, `fs_google`, `fs_exclude`). При нажатии «Использовать»
интерфейс покажет их адреса и попросит подтвердить, затем добавит списки на страницу *Списки* и скачает; дальше они
обновляются ежедневно вместе с остальными. Свои сайты добавляйте в режиме «Только мой список» (список «Через zapret» и
исключения «В обход» работают вместе с пресетом, как `list-general-user.txt` и `list-exclude-user.txt` в оригинале); в
режиме «Всё» пресет всё равно работает только по спискам. **Подмена timestamp (`ts`) работает, только если на устройстве
включены TCP timestamps:** в Android, iOS, macOS и Linux они включены, в Windows — выполните
`netsh interface tcp set global timestamps=enabled`. Без них фейк доходит до сервера как настоящие данные и соединение
ломается.

## General (ALT) + порты 1024-65535

 Пресет `general-alt-games` — это `general-alt` с двумя дополнительными профилями из
оригинала (игровой фильтр) и портами `80,443,1024-65535` (TCP) и `443,1024-65535` (UDP). Он идёт после остальных
профилей, поэтому Discord, Google и сайты общего списка обрабатываются как раньше, а всё остальное на портах от 1024
попадает в игровые профили для любых адресов (как режим «any» у ipset-all в оригинале):

| Профиль | Что делает |
|---|---|
| TCP 1024-65535 | `--out-range=<n4` (первые 3 пакета: SYN, ACK и первые данные); TLS — два фейка (`stun`, `tls_google`), HTTP — фейк `tls_vk`, неизвестный протокол — те же два фейка, затем `fakedsplit` для всего; подмена timestamp и `repeats=6` как в основном профиле |
| UDP 1024-65535 | `--out-range=<n3` (первые 2 датаграммы потока): 12 фейков `quic_initial_www_google_com.bin` перед каждой; голос Discord (UDP 19294-19344 и 50000-50100) по-прежнему обрабатывает свой профиль |

**Цена и ограничения.** Каждое новое соединение на порт ≥ 1024 (включая торренты и любой P2P) проходит первые пакеты
через `nfqws2`, а каждый новый UDP-поток получает ещё 24 лишних пакета, так что на слабом роутере растёт нагрузка на
процессор. TCP-фейки требуют TCP timestamps на устройстве и у сервера: сервер без них примет фейк за настоящие данные и
оборвёт соединение (с играми и самодельными серверами это возможно). Список «В обход» к игровым профилям не
применяется: у неизвестного протокола нет имени хоста, а `nfqws2` не выбирает профиль со списком хостов, пока имя
неизвестно (так же устроен оригинал, где там только `ipset-exclude`). Порты, проброшенные на серверы в вашей сети, не
исключаются из обработки; как `nfqws2` ведёт себя с ответами таких серверов, я не проверял. Чтобы ограничить игровые
профили нужными адресами, скопируйте пресет и добавьте в два последних профиля `--ipset=<LIST:имя>` (список вида «IP»).
Диапазоны портов в заголовке не должны пересекаться: nftables отвергает пересекающиеся интервалы.

## Свои и скачиваемые пресеты

 Файл пресета — текст: заголовок из строк `#@ключ: значение`
(`name`, `description`, `description.ru`, `tcp_ports`, `udp_ports`, опционально `tcp_pkt_out/in`, `udp_pkt_out/in`),
затем параметры `nfqws2`. Строки `#@list: id hosts|ips URL название` (до 8 штук) объявляют списки, которые нужны пресету:
при его включении они добавляются на страницу *Списки* (если списка с таким id ещё нет) и скачиваются; в теле пресета
на них ссылаются как `<LIST:id>`. Перед этим интерфейс показывает адреса и просит подтверждения. В теле работают подстановки `<HOSTLIST>`, `<HOSTLIST_NOAUTO>` (по режиму фильтрации),
`<LIST:имя>` (путь к вашему списку) и `<BASE>` (файлы zapret2). Пример — любой файл из `zapret2/presets/`.

Источник для загрузки (*Настройки → Пресеты*, затем «Скачать пресеты» или ежедневное обновление) — текстовый файл,
в котором пресеты идут подряд, каждый начинается со строки `#@id: мой-id`; файл без таких строк считается одним
пресетом, названным по имени файла. Источник можно разместить где угодно, например в репозитории на GitHub
(`https://raw.githubusercontent.com/<вы>/<репозиторий>/main/presets.txt`). Скачанные пресеты лежат в
`/etc/zapret2/presets/downloaded`, свои — в `/etc/zapret2/presets/user`; при одинаковом id приоритет у своего.

> **Безопасность.** Пресет может содержать Lua-код (`--lua-init`, `luaexec`), который выполняется внутри `nfqws2`.
> Такие пресеты помечаются в интерфейсе и требуют подтверждения при включении. Скачивайте пресеты только из
> источников, которым доверяете, желательно по https.
>
> Параметр пресета не может содержать пробелов (init-скрипт upstream передаёт параметры без кавычек): Lua-код кладите
> в файл и подключайте как `--lua-init=@<RW>/lua/файл.lua`, где `<RW>` — `/etc/zapret2`.

## Что идёт через zapret, а что мимо

**Что идёт через zapret, а что мимо.** Страница *Списки* начинается с выбора режима (карточки):

| Режим | `mode_filter` | Что делает |
|---|---|---|
| Всё | `none` | через zapret идёт весь трафик, кроме сайтов из списка «В обход zapret» |
| Только мой список | `hostlist` | только сайты из списка «Через zapret» и скачанных списков; остальное не затрагивается |
| Мой список + автоопределение | `autohostlist` | как предыдущий, плюс сайты, где блокировка обнаружена автоматически |
| По IP-адресам | `ipset` | сопоставление по IP-адресам из списков (они определяются кнопкой «Обновить списки») |

Два главных списка стоят рядом: зелёный **«Через zapret»** (`zapret-hosts-user.txt`) и красный **«В обход zapret»**
(`zapret-hosts-user-exclude.txt`). Сайт добавляется строкой ввода (можно вставить адрес целиком —
`https://www.youtube.com/watch?v=…` превратится в `www.youtube.com`) или правкой текста и кнопкой «Сохранить список».
В списке «В обход zapret» допустимы и IP-адреса/подсети (`10.0.0.0/8`). Исключения работают **во всех режимах**:
в режимах «Только мой список» и «Мой список + автоопределение» их применяет сам `nfqws2` (`--hostlist-exclude`),
в режиме «Всё» upstream список исключений игнорирует — этот порт добавляет `--hostlist-exclude` сам, а в режиме
«По IP-адресам» домены из обоих списков превращаются в IP-адреса при «Обновить списки» (после правок нажмите её).
Список «Через zapret» в режиме «Всё» не используется — страница об этом предупреждает.

Под ними — «Другие списки»: «IP-блокировки», «Автосписок», «Скачанный список» (результат скрипта *Настройки →
Списки → Скачивать списки*) и ваши собственные. Любой список можно открыть, листать постранично и искать в нём;
маленькие списки (до 256 КиБ) можно редактировать прямо в браузере. Свой список создаётся кнопкой «Добавить список»:
идентификатор, название, тип (домены/IP) и, по желанию, URL — тогда он скачивается по кнопке «Обновить списки» и
ежедневно (час задаётся в *Настройки → Списки*). В пресетах свой список подключается как
`--hostlist=<LIST:имя>` или `--ipset=<LIST:имя>`; файл лежит в `/etc/zapret2/lists/имя.txt`.

## Пустой список = «всё»

 Для `nfqws2` include-список без единой записи означает «подходит любой хост», поэтому
пустой или ещё не скачанный список в `--hostlist=`/`--ipset=` превратил бы пресет в «обрабатывать всё». Чтобы этого не
случилось, порт держит в таких списках запись-заглушку, которая ничему не соответствует (`nonexistent.domain` для
доменов, `203.0.113.113/32` для IP): её добавляют создание списка, сохранение пустого списка («Через zapret» и свои
списки), загрузка и каждый запуск службы для списков включённого пресета. В карточке «Через zapret» заглушка скрыта, в
счётчиках записей она не учитывается. Списки исключений («В обход») могут быть пустыми.
